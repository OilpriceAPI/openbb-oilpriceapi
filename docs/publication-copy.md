# Publication Copy

Use this fact-scoped description when listing the provider:

> `openbb-oilpriceapi` provides OpenBB fetchers for latest available and
> versioned historical-period OilPriceAPI records. Results retain API-provided
> timestamps, currency, unit, and source labels. Dataset access depends on the
> API key's plan, source, and account entitlements.

Use the executable direct-fetcher example from the repository README. Do not
describe `obb.commodity.oil.price` or `obb.commodity.oil.historical` as package
commands: this package does not install those router paths.

Before publishing plan limits, trial details, catalog coverage, freshness, or
data-rights language, read the current
[versioned product-facts contract](https://api.oilpriceapi.com/product-facts.json).
